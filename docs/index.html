۱ — Installation

نصب

کلنگ یک باینری تک‌فایلی است که از روی کدمنبع ساخته می‌شود. در چهار گام آمادهٔ استفاده است.

۱

پیش‌نیازها

برای ساخت کلنگ به Go نسخهٔ ۱.۲۷ یا بالاتر نیاز دارید. نصب بودن Go را این‌طور بررسی کنید:

shell — بررسی نسخهٔ Go 
$ go version
go version go1.27.0 darwin/amd64
۲

دریافت کد

مخزن پروژه را کلون کنید و وارد پوشهٔ آن شوید:

shell — دریافت کد 
$ git clone https://github.com/faralidev/kolang.git
$ cd kolang
۳

ساخت باینری

باینری kolang را از کدمنبع بسازید:

shell — ساخت 
$ go build -o kolang ./cmd/kolang
۴

بررسی نصب

برای اطمینان از درست بودن نصب، اولین برنامهٔ کلنگ را از خط فرمان اجرا کنید:

shell — بررسی 
$ ./kolang -c '«سلام کلنگ!» بنویس'
سلام کلنگ!
۲ — Quick start

راه‌اندازی سریع

سه راه برای اجرای کد کلنگ: از روی فایل، مستقیم در خط فرمان، یا در محیط تعاملی.

از روی فایل file

یک فایل .kolang را به باینری بدهید.

shell 
$ ./kolang examples/hello.kolang
سلام دنیا!

خط فرمان -c

کد را مستقیم با پرچم -c اجرا کنید.

shell 
$ ./kolang -c '«سلام» بنویس'
سلام

محیط تعاملی repl

با repl وارد محیط تعاملی شوید. برای خروج خروج را بنویسید.

shell 
$ ./kolang
کلنگ> خروج
۳ — Core concepts

مفاهیم پایه

کلنگ آشنای پایتون و گو است: متغیر، شرط، تابع، شیءگرایی، خطا، همزمانی، لوله و نوع‌نویسی تدریجی. کد ستارهٔ نمایش است.

{ } متغیر و چاپ

متغیر با = تعریف می‌شود و با بنویس چاپ می‌شود. نیازی به اعلان نوع ندارد.

نام = «کلنگ»
سال = ۱۴۰۴
نام بنویس
سال بنویس

? شرط‌ها

با اگر، وگرنه و باشد شرط می‌سازید. تورفتگی بلوک‌ها را تعیین می‌کند.

سن = ۱۸
اگر سن == ۱۸ باشد:
    «هجده ساله» بنویس
وگرنه:
    «سن دیگر» بنویس

ƒ توابع و حلقه‌ها

تابع با تعریف ساخته می‌شود و حلقهٔ شمارشی با برای ... از ... تا.

تعریف فیبوناچی(ن):
    اگر ن <= ۱ باشد:
        ن برگردان
    فیبوناچی(ن - ۱) + فیبوناچی(ن - ۲) برگردان

برای ای از ۰ تا ۱۰:
    فیبوناچی(ای) بنویس

◈ شیءگرایی

با گونه کلاس، با وارث ارث‌بری و با ساخت سازنده می‌سازید. خود همان self است.

گونه حیوان:
    ساخت (خود و نام):
        نامِ خود = نام
    تعریف صدادهی (خود):
        «صدای حیوان» بنویس

گونه سگ وارث حیوان:
    تعریف صدادهی (خود):
        «واف واف» بنویس

حیوانات = فهرست (سگ («رکس») و گربه («پشمک»))
برای ح در حیوانات:
    صدادهیِ() ح

! خطاها

با بپا شروع، با بگیر گرفتن خطا و با درنهایت پاک‌سازی انجام می‌شود.

بپا:
    «قبل از خطا» بنویس
    خطای‌مقدار(«یک مشکل!») بده
    «این چاپ نمی‌شود» بنویس
خطای‌مقدار بگیر بانام err:
    «خطا گرفته شد:» بنویس
    پیامِ err بنویس
درنهایت:
    «درنهایت اجرا شد» بنویس

⇄ همزمانی: تارک و کانال

برو یک تارک (goroutine) اجرا می‌کند و کانال ارتباط بین آن‌ها را برقرار می‌کند — درست مثل Go.

تعریف تولیدکننده():
    برای ای از ۰ تا ۴:
        ch << ای
    ch ببند

ch = کانال(صحیح)
برو تولیدکننده()
برای v در ch:
    v بنویس

|> لوله

با عملگر |> خروجی یک تابع را به تابع بعدی می‌دهید — خواندن جریان داده را ساده می‌کند.

تعریف دو‌برابر(x):
    x × ۲ برگردان

تعریف یکی‌اضافه(x):
    x + ۱ برگردان

۵ |> دو‌برابر |> یکی‌اضافه |> بنویس

:: نوع‌نویسی تدریجی

نوع‌ها اختیاری‌اند. با : نوع متغیر و با -> نوع خروجی تابع را می‌نویسید.

سن: صحیح = ۲۵
سن بنویس

تعریف جمع(الف: صحیح و ب: صحیح) -> صحیح:
    الف + ب برگردان

جمع(۱۰ و ۲۰) بنویس
۴ — REPL

محیط تعاملی

با ./kolang وارد محیط تعاملی شوید. عبارت‌ها را بنویسید و نتیجه را بلافاصله ببینید. برای خروج، خروج را بنویسید.

$ ./kolang

۵

سلام
