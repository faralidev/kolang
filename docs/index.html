مستندات کلنگ

کلنگ یک زبان برنامه‌نویسی فارسی است که برای آموزش برنامه‌نویسی به فارسی‌زبانان طراحی شده است. نحو آن طبیعی و فارسی است: افعال در انتهای جمله می‌آیند، دسترسی به اعضا با اضافه (کسره) انجام می‌شود و اعداد فارسی (۰–۹) پشتیبانی می‌شوند. کلنگ از زبان گو الهام گرفته و ویژگی‌هایی مانند تارک، کانال، تأخیر، رابط و نوع‌دهی تدریجی را ارائه می‌دهد.

ویرایشگر کلنگ (Kolang IDE) — برای تجربهٔ بهتر، افزونهٔ VS Code را نصب کنید: پشتیبانی از راست‌به‌چپ، هایلایت نحو و تکمیل خودکار. دریافت از GitHub ↗
آشنایی — کد کلنگ را اینجا بنویسید و اجرا کنید 
برای اجرا، دکمهٔ «اجرا» را بزنید

نصب

کلنگ را به چند روش می‌توانید نصب کنید. برای روش‌های مبتنی بر کدمنبع به Go نسخهٔ ۱.۲۷ یا بالاتر نیاز دارید.

روش ۱ — نصب با Go

shell
$ go install github.com/faralidev/kolang/cmd/kolang@latest

روش ۲ — نصب از سورس

shell
$ git clone https://github.com/faralidev/kolang.git
$ cd kolang
$ make build

روش ۳ — دانلود فایل اجرایی

از صفحهٔ Releases فایل اجرایی مناسب سیستم‌عامل خود را دانلود کنید.

روش ۴ — نصب در مک (Homebrew)

shell
$ brew tap faralidev/tap
$ brew install kolang

روش ۵ — نصب در ویندوز (Scoop)

powershell
> scoop bucket add faralidev https://github.com/faralidev/scoop-bucket
> scoop install kolang

بررسی نصب

shell
$ kolang -version
کلنگ نسخه ۱.۰.۰ (kolang 1.0.0)
github.com/faralidev/kolang
Go go1.27.0

شیءگرایی

با گونه کلاس، با وارث ارث‌بری و با ساخت سازنده می‌سازید. خود همان self است و والد برای فراخوانی کلاس والد به کار می‌رود.

گونه حیوان:

همزمانی

برو یک تارک (goroutine) اجرا می‌کند و کانال ارتباط بین آن‌ها را برقرار می‌کند — درست مثل گو.

تعریف تولیدکننده():

        ch << ای                       / ارسال
    ch ببند

برو تولیدکننده()                        / اجرای همزمان

تاوقتی بسته‌استِ ch نباشد:
    مقدار = >>ch                   / دریافت
    مقدار بنویس

    برو کارگر()

برای ای از ۰ تا ۵:
    >>نتایج بنویس
