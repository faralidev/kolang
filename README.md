## ۱. معرفی

کلنگ یک زبان برنامه‌نویسی فارسی است که برای آموزش برنامه‌نویسی به فارسی‌زبانان و کودکان طراحی شده است. نحو کلنگ طبیعی و فارسی است: افعال در انتهای جمله می‌آیند، دسترسی به اعضا با اضافه (کسره) انجام می‌شود، و اعداد فارسی (۰-۹) پشتیبانی می‌شوند.

کلنگ از زبان Go الهام گرفته و ویژگی‌هایی مثل تارک (goroutine)، کانال (channel)، تأخیر (defer)، رابط (interface) و نوع‌دهی تدریجی را ارائه می‌دهد.

### اصول طراحی
- **نحو طبیعی فارسی** — افعال آخر می‌آیند، «را» حذف شده
- **بدون ارزش‌حقیتی پنهان** — شرط‌ها باید صریح باشند (`اگر x == ۵ باشد:` نه `اگر x:`)
- **نوع‌دهی تدریجی** — اختیاری در زمان اجرا
- **پایداری BIDI** — عملگرهای کانال `<<` و `>>` در متن راست‌به‌چپ پایدارند
- **پیام‌های خطای فارسی** — همه خطاها به فارسی و ساده هستند

## ۴. آموزش گام‌به‌گام

### ۴.۱. اعداد و حساب

کلنگ از اعداد فارسی پشتیبانی می‌کند. اعداد در لگشر به لاتین تبدیل می‌شوند.

| عملگر | معنی | مثال |
|-------|------|------|
| `+` | جمع | `۱ + ۲` → `۳` |
| `-` | تفریق | `۵ - ۳` → `۲` |
| `×` | ضرب | `۲ × ۳` → `۶` |
| `*` | توان | `۲ * ۳` → `۸` |
| `÷` | تقسیم (اعشاری) | `۷ ÷ ۲` → `۳.۵` |
| `÷/` | تقسیم صحیح | `۷ ÷/ ۲` → `۳` |
| `%` | باقی‌مانده | `۷ % ۳` → `۱` |

```kolang
مجموع = ۱۰ + ۲۰
مجموع بنویس                          / خروجی: ۳۰

ضرب = ۵ × ۳
ضرب بنویس                            / خروجی: ۱۵

توان = ۲ * ۱۰
توان بنویس                           / خروجی: ۱۰۲۴

تقسیم = ۷ ÷ ۲
تقسیم بنویس                          / خروجی: ۳.۵
```

**اعداد ویژه:**
```kolang
اعشاری = ۳٫۱۴                        / جداکننده‌ی اعشار: ٫ یا .
گروه‌دار = ۱٬۲۳۴٬۵۶۷                  / جداکننده‌ی گروه: ٬ یا ,
مبنای‌شانزده = ۰xFF                   / مبنای ۱۶
مبنای‌دو = ۰b1010                     / مبنای ۲
مبنای‌هشت = ۰o17                      / مبنای ۸
```

**انتساب مرکب:**
```kolang
شمارنده = ۰
شمارنده += ۵                          / جمع
شمارنده -= ۲                          / تفریق
شمارنده ×= ۳                          / ضرب
شمارنده ÷= ۲                          / تقسیم
```

### ۴.۳. متن‌ها

**اندیس‌گذاری و برش:**
```kolang

معکوس = متن[::-۱]                     / گنلک
```

### ۴.۴. شرط‌ها

شرط‌ها باید با `باشد` یا `نباشد` تمام شوند. نقیض فقط با `نباشد` انجام می‌شود (`!=` وجود ندارد).

```kolang
سن = ۲۰

اگر سن >= ۱۸ باشد:
    «بزرگسال» بنویس
وگرنه:
    «کودک» بنویس

/ نقیض با نباشد:
اگر سن == ۲۰ نباشد:
    «بیست سال نیست» بنویس

/ عضویت:
اگر «ع» در «علی» باشد:
    «پیدا شد» بنویس

/ منطقی:
اگر سن > ۰ همچنین سن < ۱۰۰ باشد:
    «معقول» بنویس
```

> **نکته:** `اگر x:` مجاز نیست. شرط باید یک مقایسه + `باشد`/`نباشد` یا `درست`/`غلط` باشد.

### ۴.۵. حلقه‌ها

```kolang
/ حلقه‌ی بازه
برای ای از ۱ تا ۵:
    ای بنویس                          / ۱ ۲ ۳ ۴

/ با گام
برای ای از ۰ تا ۱۰ گام ۲:
    ای بنویس                          / ۰ ۲ ۴ ۶ ۸

/ حلقه‌ روی فهرست
اعداد = [۱۰ و ۲۰ و ۳۰]
برای عدد در اعداد:
    عدد بنویس

/ حلقه‌ روی گنجه (کلیدها)
شخص = گنجه(«نام» و «علی» و «سن» و ۲۵)
برای کلید در شخص:
    کلید بنویس                        / نام سن

/ تاوقتی
تاوقتی درست باشد:
    / ...
    اتمام                             / شکست
```

`اتمام` حلقه را می‌شکند و `بروبعدی` به تکرار بعدی می‌رود.

### ۴.۱۶. همزمانی

```kolang
ch = کانال(صحیح و ۱)                   / کانال با بافر ۱

تعریف تولیدکننده():
    برای ای از ۰ تا ۵:
        ch << ای                       / ارسال
    ch ببند

برو تولیدکننده()                        / اجرای همزمان

```

**استخر کارگر (Worker Pool):**
```kolang

        شغل = >>کارها
        اگر بسته‌استِ کارها باشد:
            اتمام
        نتایج << شغل * ۲

برای ای از ۰ تا ۳:
    برو کارگر()

برای ای از ۰ تا ۵:
    کارها << ای
کارها ببند

برای ای از ۰ تا ۵:
    >>نتایج بنویس
```

# English Section

# Kolang — Persian Programming Language

> A Persian-language scripting language for education and everyday use

Kolang is a Persian programming language designed for Persian speakers and kids learning to code. Its syntax is natural Persian: verbs come last, member access uses ezafe (kasra), and Persian digits (۰-۹) are supported.

Kolang is inspired by Go and offers goroutines (تارک), channels (کانال), defer (تأخیر), interfaces (رابط), and gradual typing.

## Installation

```bash
go install github.com/faralidev/kolang/cmd/kolang@latest
```

Or from source:
```bash
git clone https://github.com/faralidev/kolang.git
cd kolang
make build
```

## Quick Start

```bash
kolang hello.kolang       # run a file
kolang -c '«سلام» بنویس'  # inline
kolang                    # REPL
kolang -version           # version info
```

## Features

- Natural Persian syntax (verb-final, ezafe member access)
- Persian digits (۰-۹)
- Control flow: if/else, for-range, for-in, while
- OOP: classes, inheritance, super, interfaces
- Exceptions: try/except/finally
- Generators and decorators
- Concurrency: goroutines, channels (`<<`/`>>`)
- Gradual typing
- Comprehensions and pipes
- Persian error messages
